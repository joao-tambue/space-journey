# Missão Origem

Demonstração React da viagem Terra–Marte com a sonda Origem a gerir energia, modos de sobrevivência e exploração da superfície.

## Correr

```bash
npm install
npm run dev
```

## O que a demo mostra

1. Lançamento e trânsito no arco Terra–Marte.
2. Queda de energia activa a sonda.
3. Modo económico e modo sobrevivência (carga não essencial desligada).
4. Falhas de software resolvidas pela sonda.
5. Falhas além da sonda: aviso à tripulação e à Terra.
6. Toque em Marte e exploração com o rover (Jezero, Olympus Mons, Valles Marineris, calote polar, Gale).

Podes acelerar a simulação (`×2` / `×4`) ou injectar anomalias no painel da sonda.
